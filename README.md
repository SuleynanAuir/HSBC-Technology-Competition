# HSBC Technology Competition

**Silver Prize (2nd Place) · April 2024 · Technical Director**

[View the project showcase](https://suleynanauir.github.io/HSBC-Technology-Competition/)

A static presentation of an end-to-end LSTM forecasting and PPO personalized trading strategy project. Includes the supplied competition imagery, reported performance ranges, and a separate financial-data visualization gallery.

## Run locally

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Open http://127.0.0.1:8080. No build or dependencies are required. GitHub Pages serves the `main` branch root.

## Content provenance

- Award, role, date and experiment ranges are reported by the project owner.
- The 15–20% MAE/RMSE reduction versus ARIMA and ~6–11% cumulative return improvement are competition results from the supplied project summary; they are not independently reproduced here. The underlying outputs and PPO comparison baseline were not supplied.
- Three PNGs analyze the supplied HSBC financial workbook for 2014–2018. This descriptive analysis is distinct from the competition experiments and does not validate LSTM/PPO performance.
- Competition photography and HSBC logo were supplied by the project owner. This is an independent project showcase.

## Features

Responsive layout, keyboard-accessible figure tabs, enlarged image dialog, PNG downloads, expandable method and data notes, and reduced-motion support. All assets are served locally with relative paths.
